# Central de Geradores — demonstração pública v1.5 beta

**Site experimental:** https://orcafacil-dev.github.io/central-geradores-teste/

Ferramenta gratuita de criação de documentos com 15 geradores, modelos visuais, Word editável, PDF pelo navegador, HTML e TXT. Os orçamentos e o controle de gastos também exportam CSV. O currículo pode ser importado de DOCX ou TXT (texto local, sem envio ao servidor).

## Privacidade
Sem cadastro, pagamento, analytics ou upload dos documentos para nossos servidores. Os dados ficam no armazenamento deste navegador e podem ser perdidos se você limpar os dados. Backups precisam ser baixados e guardados em local privado. A hospedagem pode registrar dados técnicos de acesso. [Detalhes](privacidade.html).

## Limites
Esta é uma **demonstração beta**, não um SaaS comercial. A importação de currículo reconhece campos e seções comuns, mas não interpreta PDFs, imagens nem macros e não inventa qualificações. A geração Word simplifica algumas diagramações. Moeda e modelos fiscais são baseados no Brasil. Ferramentas legais e acadêmicas exigem revisão. Não há sincronização entre aparelhos. Use dados fictícios nos testes.

**A página permanece não indexada pelos buscadores.** GitHub Pages é usado apenas para esta demonstração e não para hospedagem comercial.
