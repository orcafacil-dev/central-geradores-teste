# Central de Geradores — demonstração experimental v1.3

15 geradores gratuitos, modelos visuais e exportação PDF, Word, TXT e HTML.

## Interface v1.3
- Modelos escolhidos por cartões; sem seletor duplicado.
- Cores, fontes e tamanho com controles compactos; cores extras em painel acessível.
- Identidade visual opcional recolhida; logotipo com prévia local.
- Arquivos agrupados em menu de exportação.

Todos os dados permanecem no armazenamento local deste navegador. Não há sincronização. Faça backups JSON. Este site é demonstração experimental; evite dados sensíveis.
